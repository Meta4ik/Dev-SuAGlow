What's New in v1.1.0

August 2026 Update

🎨 Visual & UI Polish

  • Date Formatting: Clean M/D/Y format with stacking. Opened is green, Resolved is red. Empty dates show a calendar.
  • "Add Task" Pill: The new task button is now a neat, pill-shaped UI element.
  • Row Separators: Darkened horizontal lines for better definition.
  • Adjustable Columns: Added horizontal drag-to-resize handles on Topic / Issue and Resolution headers.

🗂️ Organization & Sorting

  • Drag-and-Drop: Use the grip icon to manually rearrange rows.
  • Header Sorting: Click any header to instantly sort alphabetically or chronologically.
  • ID Formatting: Single-digit IDs now pad with a zero (e.g. #02) and sort correctly.

🏷️ Filtering

  • Area Colors: Rows are color-coded based on Area (with new Provider/Ops colors).
  • Interactive Legend: The visual legend doubles as a multi-select checkbox filter.

🛡️ Quality of Life

  • Global Undo: Hit the Undo button (or Cmd/Ctrl+Z) to revert edits or sorts.
