# Exoblanc Boosting Serum — Mobile Web App Experience

A mobile-first, responsive luxury web application designed for **SuA Glow** (Carrollton, TX) and **Exoblanc Boosting Serum**, capturing the aesthetic of high-end Korean medical esthetics.

## 📱 Features

1. **Brand & Visual Identity**:
   - Palette: Warm alabaster cream (`#FAF7F2`), muted warm taupe (`#7D6B5B`), champagne gold, and soft charcoal.
   - Typography: Editorial high-contrast serif (`Cormorant Garamond`) paired with modern clean sans (`Plus Jakarta Sans`).
   - Authentic assets cropped directly from the client's creative board.

2. **Mobile Web App UX**:
   - **Interactive Media Showcase**: Segmented mobile tab bar to switch between *Skin Result* (Model), *The Bottle*, *Dewy Texture*, and *Campaign*.
   - **Sticky Bottom Action Dock**: Mobile-first bottom bar with `$TBD` pricing, 50 mL indicator, and quick "Book Consultation →" button.
   - **Interactive Consultation Drawer**: iOS-style sliding bottom sheet for scheduling personalized skin evaluations (In-Clinic in Carrollton vs Virtual).
   - **Smooth Accordions**: Expandable details for *Glow Details* and *Frequently Asked Questions* with clinical dermatological information.
   - **Desktop Presentation Mode**: Toggle between an iPhone 16 Pro device frame preview and full responsive fluid layout.

## 🚀 How to View & Run

### Instant Preview (macOS):
Simply open `index.html` in your default browser:
```bash
open /Users/mw/.gemini/antigravity/scratch/exoblanc-mobile-app/index.html
```

Or start a local web server:
```bash
cd /Users/mw/.gemini/antigravity/scratch/exoblanc-mobile-app
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in your mobile or desktop browser.
